# myants

Ant colony simulation for desktop (JVM) and the browser (Kotlin/JS), rendered with kool 0.19.0.

The simulation behaviour and the English/German UI copy follow [AntSim_V2](https://github.com/nilsgollub/AntSim_V2) by nilsgollub, MIT license. See [docs/programming/THIRD_PARTY_NOTICES.md](docs/programming/THIRD_PARTY_NOTICES.md). Intentional differences are in [docs/programming/myants_antsim_deviations.md](docs/programming/myants_antsim_deviations.md).

```bash
./gradlew :koolApp:runDesktop
./gradlew :koolApp:jsBrowserDevelopmentRun
```
