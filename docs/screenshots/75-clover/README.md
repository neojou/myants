## 地面（世界區域中位數，粗略）
- 日：main (166,136,97)，B/R 0.58 → 本分支 (168,145,114)，B/R 0.68。
- 夜：main B/R 約 0.80 → 本分支約 0.89。夜/日比從 1.38 變成 1.31，**低於 #68 的 1.35**。原因是日間地面變中性。

## 限制
- 夜間的花太暗，色相分類不可靠（lilac 會抓到大片夜色），所以夜間 ΔE 不列。
- main 的花色和本分支差很多，同一組門檻挑不到 main 的花，所以沒有列 main 的 ΔE。基準請用 QE 在 #74 的實測：rose–lilac 11–13、gold–葉 15–16。
