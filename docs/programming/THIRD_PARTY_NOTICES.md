myants includes a Kotlin reimplementation of simulation behaviour and UI copy
from AntSim_V2. The original project is MIT-licensed. Its copyright notice and
license text follow.

## Geometry and icons

The outdoor ant is an original glTF 2.0 model, `koolApp/assets/models/ants/worker_black.glb`, generated by `tools/make_black_ant_glb.py`. It is not taken from Sketchfab or AntSim. Soil, grass, rocks, flowers, the clock stone, rain, the nest cutaway, and the block-ant fallback are procedural meshes in `com.neojou.myants.render3d`.

Toolbar glyphs stay ASCII (`||`, `>|`, `?`, `S`, `P`, `E`). Material Symbols SVGs were not vendored in this tree. If a later build adds them, they are Apache-2.0 from Google Material Symbols, and a missing file must fall back to these ASCII labels.

No kool-demo shader source was copied.
