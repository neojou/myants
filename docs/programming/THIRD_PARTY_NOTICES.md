## Geometry and icons

The outdoor ants are original glTF 2.0 models, `koolApp/assets/models/ants/worker_black.glb` and `soldier.glb`, generated by `tools/make_black_ant_glb.py`. The outdoor prey, predator, spider, beetle, and ladybug are original models in `koolApp/assets/models/insects/`, generated by `tools/make_outdoor_insects_glb.py`. The green aphid is likewise original. None of these are taken from Sketchfab or AntSim. Soil, grass, rocks, flowers, the clock stone, rain, the nest cutaway, and the block fallbacks are procedural meshes in `com.neojou.myants.render3d`.

HUD toolbar icons (Speed, Zoom, Tool rows) are Material Symbols Rounded SVGs (opsz 20, wght 400, FILL 0; `*_fill.svg` = FILL 1) by Google, Apache License 2.0, from https://github.com/google/material-design-icons (`symbols/web/<name>/materialsymbolsrounded/`). The only change is `fill="#FFFFFF"` on the path so kool can tint them. Vendored in `koolApp/assets/icons/`:

## Fonts

English and German interface text, and the HUD digit slots, use kool's bundled Fira Sans MSDF.

Traditional Chinese and Japanese use an MSDF atlas generated from Noto Sans CJK TC (also known as Source Han Sans), weight 400. Copyright 2014-2021 Adobe. Reserved Font Names include "Source Han Sans" and "Noto Sans CJK". Licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org). The full font file is not in this repository. The atlas is `koolApp/src/commonMain/resources/fonts/noto-sans-cjk.json` and `noto-sans-cjk.png`, and it contains only glyphs the interface draws.
