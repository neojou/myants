# 3D 畫面對照（2026-10-19，macOS，Apple M4 Pro，Vulkan / MoltenVK）

四張圖都是 `--seed=12345 --quality=medium`，1600×900。`day` / `rain` / `ant` 把時刻鎖在日長的 0.45（中午）。`night` 鎖在 0.92。`rain` 另外把 `raining` 打開。`ant` 的縮放是 6。HUD 的 Queen Age 用的是蟻后自己的 `age`，所以中午的圖仍可能顯示 `0m 2s`。

FPS 是 HUD 讀數，不是驗收條件的測量。這四張都在族群 34 左右，大約 43–48 fps。Medium 雙群 300 蟻 ≥ 60 fps、Ultra 1200 蟻 ≥ 30 fps 沒有量。

## 對 `ui_hud_aesthetics.md` §6

1. 世界佔左 74%，右側 26% 是巢穴，跟 AntSim 的版面相同，不是整窗 85% 都是世界。UI 是深色、低彩度。
2. HUD 有數字。強調色只有檢查器按鈕的淡紫 `[?]`。
3. 右上工具列有畫出來，但是一排很小的青色方塊，沒有等寬文字按鈕，也沒有群組間距可對。
4. 食物與費洛蒙會發光。時鐘數字是平的米色方條，不是高亮。UI 本身不發光。
5. 夜間 UI 維持原亮度，世界變暗，食物與費洛蒙更顯眼。右側巢穴是不隨日光變暗的剖面。
6. HUD 用 Fira MSDF，這張圖上的英文沒有糊。沒有另做 Retina dp 檢查。CJK MSDF 不在這次範圍。
7. 沒有 tooltip，快捷鍵沒有寫在圖示上。圖示是 ASCII，不是 Material Symbols。

Grafik 的 Classic 2D / 3D 切換、品質檔位、以及每個 AntSim 按鈕，這次只確認它們出現在畫面上，沒有逐一點過。
